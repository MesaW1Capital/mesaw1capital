01O que foi feito

De 150 mil linhas ao vivo para uma fatia por pessoa em segundos.

O painel lia as abas gigantes (Under e Over ~150 mil linhas, Granular ~20 mil) ao vivo a cada acesso — por isso demorava — e faltava um controle individual e seguro por e-mail.

⚡

Velocidade — "fatias" (shards)

Um gatilho diário lê as abas pesadas uma única vez, quebra os dados por assessor e por time, e grava um JSON pequeno por pessoa no Drive. No login, o painel lê só a fatia daquela pessoa → carrega em segundos. Se a fatia não existir, ele cai no modo "ao vivo" automaticamente.

👥

Líderes leves + drill-down

A fatia do líder guarda só o consolidado (Visão Líder PJ1/PJ2). O detalhe cliente-a-cliente carrega quando o líder escolhe um assessor no topo. Exemplo real: Mesa Digital caiu de ~8 MB para ~5 KB.

🔒

Segurança OAuth

O Client Secret saiu do código e foi para as Propriedades do Script (e foi rotacionado). App publicado como "Em produção" (Externo). Trava de domínio ativa, e login abre direto no painel.

↻

Atualização imediata

O cache é versionado: rodar "Reconstruir fatias" reflete os dados novos na hora. O teste testarAmostra confirmou que as fatias gravadas são idênticas ao cálculo ao vivo.

02Camadas de segurança

Cinco camadas protegem o painel hoje.

Cada camada é independente. Precisa passar por todas para ver qualquer dado.

  1. 01🔐

    Login Google (OAuth)

    Só quem tem uma conta Google consegue tentar entrar.

  2. 02🛡

    Trava de domínio

    Apenas e-mails @w1capital.com.br passam do login. Qualquer outro recebe "Acesso restrito a e-mails corporativos" e nem entra.

  3. 03👥

    Allowlist nas abas

    Dos que passam, só quem está nas abas "Acessos Individuais" / "Acessos Time" (com e-mail preenchido) vê dados.

  4. 04✦

    Escopo por perfil

    AAI vê a própria carteira, líder vê o consolidado do time e o detalhe dos assessores dele, admin vê tudo.

  5. 05⚡

    Roda como o dono

    Ninguém precisa de acesso à planilha — o script lê pelos usuários. As fatias ficam no seu Drive, não expostas publicamente.

Configurável em Code.gs na linha var ALLOWED_DOMAINS.

03Manual de acessos

Adicionar, remover ou trocar — na hora.

Regra de ouro: mudanças de acesso valem imediatamente. O login lê as abas ao vivo — não precisa reconstruir fatias nem republicar para adicionar/remover pessoas. Reconstruir só é necessário quando muda o agrupamento de times ou os dados.

➕

Adicionar um assessor (AAI)

  1. 1. Abra a aba "Acessos Individuais".
  2. 2. Ache a linha da pessoa (Nome/Código) e preencha a coluna E-mail com o endereço @w1capital.com.br.
  3. 3. Pronto — no próximo login ela entra e vê a própria carteira.

Se for um assessor novo no Granular, rode antes "Configurar abas de acesso" para ele aparecer, e depois "Reconstruir fatias agora".

➕

Adicionar um líder

  1. 1. Aba "Acessos Time" → ache a linha do líder (Perfil = Lider, Time correto) e preencha o E-mail.
  2. 2. Já funciona no próximo login. Para ficar 100% otimizado, rode "Reconstruir fatias agora".
➕

Adicionar um admin

  1. 1. Aba "Acessos Time" → crie uma nova linha no fim: Nome, E-mail, Perfil = Admin, Time em branco.
  2. 2. Vale no próximo login. Admin vê tudo.
➖

Remover um acesso (qualquer perfil)

  1. 1. Apague o E-mail da linha da pessoa (ou apague a linha inteira).
  2. 2. No próximo carregamento ela é bloqueada ("E-mail não cadastrado"). Sessão em aberto expira em até 6h.
↻

Trocar alguém de time

  1. 1. Aba "Acessos Individuais" → mude o valor da coluna Time.
  2. 2. Rode "Reconstruir fatias agora" para o consolidado dos times refletir a troca.
🛡

Liberar outro domínio de e-mail

  1. 1. No Code.gs, edite var ALLOWED_DOMAINS = ['w1capital.com.br']; — ex.: ['w1capital.com.br','w1.com.br'].
  2. 2. Republique (Implantar → nova versão) — mudou o código.
⚠️

Atenção: não rode "Configurar abas de acesso" à toa — ele reconstrói a lista de líderes e pode desfazer edições manuais (como os admins que você definiu). Se precisar rodar, confira depois as linhas de Admin.

04Atualização dos dados

Basta atualizar o Sheets? Quase.

Os números do painel vêm das fatias, reconstruídas automaticamente ~11h e ~13h, ou na hora se você rodar "Reconstruir fatias agora".

📅

Automático (2×/dia)

O gatilho roda por volta das 11h e das 13h. Se você atualizar a planilha, o painel mostra os números novos no próximo horário, sozinho.

O agendador do Google roda numa janela de ±15 min — por isso "por volta das 11h e 13h", não cravado no minuto.

↻

Na hora

Rode "W1 Painel → Reconstruir fatias agora". Com o cache versionado, o efeito é imediato no próximo login. Você não precisa mexer em HTML nem republicar para atualizar dados.

O que cada mudança exige

O que você fezReconstruir fatias?Republicar?
Atualizou números na planilhaSim, para ver na hora (ou espera o rebuild das ~11h/13h)Não
Adicionou ou removeu pessoa (e-mail)Não — vale na horaNão
Adicionou líder novo ou trocou alguém de timeSim (para o consolidado do time)Não
Mudou visual, coluna ou regra (código)NãoSim
Mudou ALLOWED_DOMAINS (domínios)NãoSim

Para mudar o próprio código (Code.gs ou Index.html): Implantar → Gerenciar implantações → Editar → "Nova versão" → Implantar (a URL continua a mesma).

07Opcional

Trocar o ícone da aba (favicon) pela logo da W1.

Hoje a aba mostra o ícone padrão do Apps Script. O método de favicon só funciona com uma imagem hospedada num link (não aceita base64). Como você já tem o GitHub Pages, o caminho é:

  1. 01

    Suba a imagem no GitHub.

    No repositório mesaw1capital, clique em Add file → Upload files, arraste o arquivo favicon.png (a marca "W1" extraída do projeto) e clique em Commit changes.

  2. 02

    Confirme o link.

    A imagem fica em https://mesaw1capital.github.io/mesaw1capital/favicon.png — abra no navegador pra ver se aparece.

  3. 03

    Aponte o código para o link.

    No Code.gs, troque a linha do favicon (começa com var FAVICON = 'data:image/png;base64,...') por: var FAVICON = 'https://mesaw1capital.github.io/mesaw1capital/favicon.png';

  4. 04

    Republique.

    Implantar → Gerenciar implantações → Editar → Nova versão → Implantar. Depois abra o painel — o ícone da aba deve virar a logo da W1. Se não mudar na hora, é cache do navegador: force Ctrl+Shift+R.

Se preferir hospedar em outro lugar, use qualquer URL pública — só troque o endereço no Code.gs.
